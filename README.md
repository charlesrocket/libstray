# `STRAY`
[![CI](https://codeberg.org/charlesrocket/libstray/badges/workflows/ci.yml/badge.svg?branch=trunk)](https://codeberg.org/charlesrocket/libstray/actions)
[![CD](https://github.com/charlesrocket/libstray/actions/workflows/cd.yml/badge.svg?branch=trunk)](https://github.com/charlesrocket/libstray/actions/workflows/cd.yml)

Manage system tray icons and menus via [D-Bus](https://www.freedesktop.org/wiki/Software/dbus/), no Glib/GTK/QT/etc. Works with any environment that supports [`StatusNotifierItem`](https://www.freedesktop.org/wiki/Specifications/StatusNotifierItem/) (**GNOME** via `libappindicator`).

🚧

* dynamic icons
* menu
